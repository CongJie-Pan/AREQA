  這是 Render 在告訴您：「如果您想使用  areqa.com  這個網址，您必須去您的『網域註冊商』那邊，把這個網址的流量導向給 Render。」

  這是一個很常見的設定流程，我為您白話翻譯一下這段訊息的意思：

  ### 1. 您真的有買下  areqa.com  嗎？

  如果您只是在 Render 的後台隨便輸入一個  areqa.com  來測試，那這一步是絕對不會成功的喔！
  網址（Domain）是需要花錢向網域商（例如 GoDaddy, Cloudflare, Namecheap, 遠振, 捕夢網等）購買租用的。如果您還沒買下這個網址，請先去購買。

  ### 2. 如果您已經買了，要怎麼設定？

  這段訊息是在給您 DNS 設定參數。您必須登入您購買網域的平台（例如 GoDaddy 後台的 DNS 管理頁面），然後新增兩筆紀錄：

  • 第 1 筆：讓大家輸入  www.areqa.com  時能連過來
      • 類型：選擇  CNAME 
      • 名稱 (Host / Name)：填寫  www 
      • 目標值 (Value / Target)：填寫  areqa-frontend.onrender.com 
  • 第 2 筆：讓大家輸入  areqa.com （不加 www）時能連過來
      • 類型：如果您的平台支援  ALIAS  或  ANAME ，就選這個，目標值填  areqa-frontend.onrender.com 。
      • 類型：如果平台只支援最傳統的  A 紀錄 ，請新增一個  A 紀錄 ，名稱填  @ ，IP 位址填寫 Render 給您的  216.24.57.1 。


  ### 3. 為什麼 Render 會說 "We weren't able to verify..." (無法驗證)？

  因為 Render 去網際網路上查，發現  areqa.com  的流量根本沒有指向 Render 的伺服器。
  如果您已經去 GoDaddy 等平台設定好了，請耐心等待！DNS 的生效時間通常需要 幾分鐘到 24 小時 不等。設定好之後放著，晚點再回 Render 點擊驗證即可。
