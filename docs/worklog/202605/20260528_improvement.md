# 系統待改善之處與未來發展方向 (Future Work)

基於前期的綜合評估報告（Comprehensive Evaluation）與各階段的消融實驗日誌，本文件彙整了 RA-LLMs 古漢語問答系統目前面臨的核心限制，並針對這些痛點提出具體的改善藍圖。這些分析不僅反映了技術實作上的妥協，更揭示了人工智慧在跨足「數位人文」領域時所遭遇的深層挑戰。

---

## 1. 致命的「檢索後扭曲」（Contextual Hallucination）

### 🔍 問題描述
儘管系統具備極高的脈絡召回率（Context Recall 達 81.74%），能夠精準擷取出回答所需的古文段落，但在最終的文本生成階段，卻經常發生「拿著正確證據，得出錯誤結論」的現象。例如在分析賈府衰敗時，模型雖然檢索到了「樹木山石也還蒼翠」的原句（原意為表面仍維持氣派），卻為了迎合「賈府荒蕪」的預設論點，強行將此句曲解為內部衰敗的證據。這種「帶著證據胡編」的現象，導致系統在 RAGAS 忠實度（Faithfulness）指標上受到嚴厲懲罰。

### 🛠️ 改善策略
* **強化對齊約束（Alignment）**：在未來的 Instruction Tuning 階段，必須加強「忠實於文本語境」的損失函數權重，或透過 Contrastive Decoding（對比解碼）技術，在生成時抑制那些與 Context 語義相悖的詞彙機率。
* **分離檢索與推理步驟**：採用 Chain-of-Thought（思維鏈），要求模型在回答前先「客觀翻譯/摘要」檢索到的文獻，再基於該摘要進行「主觀文學推論」，避免一步到位的生成導致語意被隱性扭曲。

---

## 2. RAG 檢索雜訊與「注意力失焦 (Lost in the Middle)」

### 🔍 問題描述
消融實驗中出現了一個違反直覺的現象：只提供 1 篇參考文獻（Top-K = 1）的表現，竟然優於提供 3 篇或 5 篇。這強烈暗示了輕量級模型（如 8B 參數規模）在處理大量、高密度的文言文 Context 時，極易產生「注意力失焦」，被無關的雜訊牽著走。此外，實驗也發現開啟 HyDE（假設性文檔嵌入）在古文場景中會產生副作用，因為模型預先盲猜的白話文答案，往往偏離了文言文的「微言大義」，進而引導檢索器抓取錯誤的段落。

### 🛠️ 改善策略
* **引入上下文壓縮（Context Compression）**：利用如 LLMLingua 等提示詞壓縮技術，在將檢索到的多篇文獻餵給生成模型前，先剔除無關的冗言贅字。
* **動態重排閾值（Strict Reranker Threshold）**：放棄固定的 Top-K 策略，改為設定嚴格的相似度分數閾值。只有真正高度相關的文獻才允許進入 Context Window，寧可 Context 較少，也不要塞入雜訊。

---

## 3. 訓練資料矛盾導致的「幻覺誘發」

### 🔍 問題描述
經過對 `v4_B` 訓練集的深入盤點，發現部分 Instruction Tuning 的樣本存在致命的邏輯矛盾。資料集中包含了教導模型「在 RAG 文本不足時，使用內部知識補全」的示範。這直接打破了本系統最核心的防線——「無文獻佐證即明確拒答」。當模型被鼓勵動用先驗權重（Parametric Knowledge）來盲猜古文細節時，往往就會產生張冠李戴的事實性幻覺。

### 🛠️ 改善策略
* **清洗訓練集與強化「拒答訓練 (Negative Rejection)」**：全面盤點並刪除所有鼓勵模型自行腦補的訓練資料。同時，大幅增加「Context 證據不足 ➡️ 模型回答『根據現有文獻無法得知』」的正向樣本，確保模型具備堅定的拒答能力。

---

## 4. 評估框架侷限與「Human-in-the-loop」的迫切性

### 🔍 問題描述
主流的量化指標（如 BERTScore 或 RAGAS）本質上是為精確問答（如醫療、法律）而設計的，對文學分析極度「水土不服」。BERTScore 會懲罰模型優美的文學過渡句與感性修辭；RAGAS 的絕對忠實度會扼殺模型對「千紅一窟」等深層隱喻的學術延伸。即便是 LLM-as-a-Judge（如 Claude），也容易陷入理科式的死摳細節，無法量化一段分析是否具備「文學美感」或「教學共鳴」。

### 🛠️ 改善策略
* **引入 Human-in-the-loop（真實教學場景回饋）**：未來的系統優化不能再單純依賴自動化跑分。必須將系統部署至真實的國文課堂，由教師與學生進行試用。
* **直接偏好最佳化（DPO / Preference Tuning）**：收集人類專家對於「好答案」的偏好排序（例如：認可適度的隱喻延伸、讚賞條理分明的結構），並透過 DPO 將這些符合真實教學需求的人類直覺反向對齊至模型中。

---

## 5. 從單一任務侷限邁向「全方位教學代理人 (Embodied Educational Agent)」

### 🔍 問題描述
目前的系統主要針對「文本事實擷取」與「人物關係/性格分析」進行高度優化，互動模式較為單一。這種將 AI 侷限於單次問答的「解題機」模式，忽略了教學現場的動態性與師生互動的隱含需求。真實教學中，學生的提問往往是模糊且缺乏明確指令的（Under-specified），且系統缺乏對個別學生程度的長期記憶與觀察，無法主動提供客製化的學習鷹架。

### 🛠️ 改善策略
為突破單一任務侷限，未來將參考 General User Models (GUM) 的全域整合架構與線上強化學習（Online RL）回饋閉環，將系統升級為具備長期記憶與動態適應能力的「專屬國文家教」：

* **建立領域專屬使用者模型 (Domain-Specific GUM) 與長期記憶**：
  不再侷限於單次被動問答，而是記錄並觀察學生長期的閱讀與提問軌跡。系統將根據互動歷史（例如學生頻繁詢問字詞典故），主動建立「學生知識地圖（Student User Model）」。當預判學生文言文底子較弱時，不待學生要求，系統便主動在後續回答中增補基礎字詞注釋；反之則提供學術深讀版解析。

* **挖掘「隱含需求」與帶有優先級的指令微調 (Instruction Tuning)**：
  針對人類提問通常簡略模糊的特性，透過分析弱模型的「失敗模式」（如：字數過長、語氣輕浮），反推出教學現場中「沒說出口但極其在乎」的隱含需求（如：原文考證、國文老師語氣）。在 RA-DIT 微調中，加入這些隱含需求並設定優先級（例如：堅守事實正確性優先於字數限制），讓模型在面對模糊指令時自動啟動教學潛規則。

* **擴充多樣化教學情境與「零樣本泛化 (Zero-shot Generalization)」**：
  在微調語料中納入更多元的教學指令，例如：「蘇格拉底式提問」（用引導問題取代直接給答案）、「跨文體改寫」（文言文改編短劇腳本）或「自動命題」（生成附詳解的考題）。透過豐富指令集賦予模型舉一反三的能力，從容應對各種未經訓練的客製化教學任務。

* **建構教育版線上強化學習 (Online RL) 與資料飛輪 (Data Flywheel)**：
  記錄師生真實互動訊號（如：點擊有幫助、追問頻率、老師標記適用性、學習成效前/後測）。初期先優化外圍的「決策策略（Orchestration Policy）」（如：何時拒答、何時給白話摘要、何時推薦下一題），待成熟後再透過直接偏好最佳化 (DPO) 與局部 Online RL 持續更新模型，形成人機協同的資料飛輪，讓系統越教越準。

---

後續研究預計將朝RAG檢索優化、模型優化與實務驗證三面向進行。在RAG檢索優化上，未來擬提升RAG文獻篩選的精準度，避免模型因閱讀過多資訊而失焦；模型優化上，在指令微調階段強化「無佐證即拒答」之語料，以增強防幻覺能力，並加入引導式提問等多樣化情境語料，提升系統適應不同互動的能力；在實務驗證上，後續將邀請國文專家與師生實際試用，並導入高中課堂進行前、後測對照，評估其作為輔助教學工具之實際效益。

---

後續研究方向 (可能之研究題目)：

1. **領域專屬使用者模型 (Domain-Specific GUM) 在文言文學習之應用與實證**
   - **解決問題：** 單次問答的「解題機」模式無法提供連貫體驗，且系統缺乏對個別學生語文程度的長期記憶，導致教學內容過深或過淺，無法落實因材施教。
   - **研究說明：** 探討如何建立具備動態適應能力的「全方位教學代理人」。透過紀錄學生的閱讀與提問軌跡建立專屬知識地圖，使系統能主動發現學生的文言文弱點，並在後續互動中自動增補基礎注釋或提供進階解析，解決單一互動模式無法客製化學習鷹架的痛點。

2. **基於線上強化學習 (Online RL) 與人類偏好對齊 (DPO) 的教育代理人優化機制**
   - **解決問題：** 模型一次性微調後無法隨真實教學場景動態進化，且單純追求基準測試分數，忽略了師生在真實課堂上對「教學適用性」與「易用性」的偏好（如：長篇大論導致學生跳出、不確定時的硬答）。
   - **研究說明：** 研究如何收集師生的日常互動（如追問頻率、拒絕建議、停留時間與後測成績）作為回饋訊號。藉由建立「決策策略（Orchestration Policy）」與人機協同的「資料飛輪」，解決系統上線後無法持續成長的瓶頸，讓系統自動學會判斷「何時該給白話摘要」、「何時該拒答」。

3. **針對「隱含教學需求」的指令微調 (Instruction Tuning) 策略與零樣本泛化**
   - **解決問題：** 學生在提問時往往給出簡略、模糊的指令，並未明確說出「請用老師語氣」、「必須引經據典」等隱含需求，導致模型回答風格與教學場景嚴重脫節。
   - **研究說明：** 探究如何透過分析弱模型的「失敗模式」（如字數失控、語氣輕浮），反推並量化人類未說出口的「教學潛規則」。藉由建立帶有優先級的指令微調（如：事實正確性優先於字數限制），提升系統對模糊提問的適應力與處理未見客製化教學任務的零樣本泛化能力。

4. **高密度古文語境下 RAG 系統的檢索降噪與動態上下文壓縮技術**
   - **解決問題：** 輕量級模型（如 8B 參數規模）在面對大量、高密度的文言文參考文獻時，極易產生「注意力失焦 (Lost in the Middle)」，被無關雜訊牽著走而偏離正確答案。
   - **研究說明：** 研究動態重排閾值（Strict Reranker Threshold）與提示詞壓縮技術（如 LLMLingua）。旨在剔除檢索到的無關冗字，確保只有真正高度相關的核心文獻進入上下文視窗（Context Window），解決因過多文獻雜訊導致模型推理失敗的技術瓶頸。

5. **預防大型語言模型在古籍問答中產生「檢索後扭曲」與幻覺的對齊方法**
   - **解決問題：** 系統雖能精準檢索古文證據，但模型常為了迎合使用者預設立場，或動用自身權重盲猜，產生「拿著正確證據，得出錯誤結論」的事實性幻覺。
   - **研究說明：** 探討如何利用「思維鏈 (CoT)」強制分離客觀翻譯與主觀推論步驟，並大幅強化「無佐證即拒答 (Negative Rejection)」的防禦性訓練。此研究旨在從根本解決系統在忠實度 (Faithfulness) 指標上表現不佳的致命缺陷，確保學術嚴謹性。
