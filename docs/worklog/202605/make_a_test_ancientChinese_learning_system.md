Sherry Wu 在 Podcast 中提到，他們為了解決這個問題，設計了一套訓練流程。我們可以拆解成三個步驟，並用兩個例子來解釋（包含她 Podcast 的例子，以及套用到你的《紅樓夢》系統）：

***

### 步驟一：用「不同能力的模型」找出失敗模式
如果我們只用最聰明的模型（比如 GPT-4），它可能大部分都做得不錯，我們就看不出「人類到底省略了什麼」。但如果我們把同樣的模糊指令，丟給能力較弱、較笨的模型，它們就會**「用各種千奇百怪的方式搞砸」**。透過觀察這些搞砸的方式，我們就能反推出人類其實有要求，只是沒寫出來。

### 步驟二：整理「隱含需求清單」
從搞砸的結果中，把人類沒寫在指令裡，但心裡其實在乎的潛規則（隱含需求）一條一條列出來。

### 步驟三：設定「優先級排序」
因為隱含需求太多了，有時候模型無法全部滿足。所以要教模型像人類一樣判斷：**「哪裡搞砸會被罵爆（絕對不行），哪裡搞砸可以被原諒（稍微放水）。」**

### 傳統的 Instruction Tuning 怎麼做？
在傳統的做法中，我們餵給模型的訓練資料（Training Data）通常是很死板的對應關係：
*   **指令：** 「請將以下句子翻譯成英文：你好。」
*   **期望輸出：** 「Hello.」
模型學到的是：「只要看到明確的指令，我就照做。」但問題在於，如果人類給的指令很模糊（例如只丟一句「你好，英文」），模型可能就會不知所措。

### Sherry Wu 的解法如何應用在 Instruction Tuning 上？

Sherry 的方法改變了我們 **「準備訓練資料（Instruction-Response pairs）」** 與 **「設定損失函數 / 獎勵機制（Loss Function / Reward）」** 的方式。應用在指令微調上，具體包含以下兩個層次：

#### 1. 豐富訓練資料：擴充「隱含指令」的資料集
既然人類很懶，給的指令很模糊（規範不足 / Under-specified），我們在進行 Instruction Tuning 時，就不能只用「完美的指令」來訓練模型。

*   **做法：** 收集大量簡短、模糊的真實人類指令。然後，研究人員（或使用更強大的模型做輔助）為這些模糊指令撰寫出「完美滿足所有隱含需求」的標準答案。
*   **微調效果：** 當你把這組資料（模糊指令 ➡️ 包含隱含需求的完美答案）丟給模型做 Instruction Tuning (Supervised Fine-Tuning, SFT) 後，模型就會產生「舉一反三」的直覺。下次它看到一句很短的「給我一些 AI 測驗題」，它的大腦（神經網路）就會自動啟動隱含規則的權重，生成多樣化且附帶解答的題目，而不會只生成無聊的問句。

#### 2. 結合 RLHF（人類回饋強化學習）處理「優先級排序」
Sherry 提到「偏題絕對不行，但字數稍微超過沒關係」，這種判斷輕重緩急的能力，通常很難只靠傳統的 SFT 做到。這時就可以運用 Instruction Tuning 的進階版——**RLHF（Reinforcement Learning from Human Feedback）** 或是 **DPO（Direct Preference Optimization）**。

*   **做法：** 針對同一個模糊指令，你準備幾個不同的模型生成結果，並給予不同的「獎勵分數（Reward Score）」。
    *   結果 A（完全偏題，但字數完美符合）：**給 0 分（重罰）。**
    *   結果 B（切中核心，有給解答，但字數稍微超標）：**給 80 分（輕罰）。**
    *   結果 C（切中核心，有給解答，字數也完美）：**給 100 分。**
*   **微調效果：** 透過這種帶有優先級梯度的指令微調，模型會學到一種「價值觀」：**「如果我無法完美兼顧所有要求，我寧可犧牲字數（次要需求），也絕對不能給錯答案（核心需求）。」**
