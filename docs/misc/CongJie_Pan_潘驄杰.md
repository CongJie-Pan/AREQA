# CongJie Pan

AI 教育科技 LLM 知識問答 智慧學習系統

我專注於「AI 與教育」的跨域結合，致力於建構以人為本的 AI 教育系統。我深信科技不應是取代思考的捷徑，而是搭建引導學習者深度探索知識的鷹架。我的技術實踐主要為建構學習系統、LLM 知識問答系統：1) 《紅樓慧讀》：紅樓夢閱讀學習系統；2)《紅樓夢》古漢語知識問答系統。

## 完成專案

-   **AREQA：個性化教育學習 AI 問答系統**
    
    -   AREQA 旨在解決許多學生使用 AI 學習時，常遇到「AI 一次給太多標準答案、不了解自己的程度，也不會在卡關時主動引導」的問題，因此 AREQA 會記住學生的學習狀態與偏好，依照程度調整說明、用鷹架式提問引導思考，並在需要時主動提供關懷與學習支持。
    
      [系統網站](https://areqa-intropage.onrender.com/)
    
-   **紅樓慧讀：紅樓夢閱讀學習系統**
    
    -   主導設計並開發一套整合 AI 技術的古典文學學習平台，解決現代讀者閱讀《紅樓夢》的三大痛點：古漢語障礙、人物關係複雜、閱讀動機難維持。
    -   核心功能包括：基於 LLM 的知識圖譜自動生成與視覺化、AI 智慧問答系統、遊戲化閱讀機制（身份進階、成就徽章），系統已部署上線運營。
    
      [系統網站](https://the-chamber-of-red-mansion-fire-bas.vercel.app/)
    
-   **GraphJudge TextToKG Pipeline - 基於LLM的高效可靠古漢語文本到知識圖譜生成器**
    
    -   這是一個基於大型語言模型輸出與評估的系統，能夠可靠地從古漢語文本輸入生成高品質知識圖譜，運行於Streamlit平台。
    
      [程式碼](https://reurl.cc/GNRMLd)
    
-   **HeartFeltAI - AI婚禮邀請函系統**
    
    -   「HeartFeltAI」是一個結合AI與人情味的婚禮邀請函生成系統，利用先進的AI技術為每位賓客創造獨特且個人化的邀請函內容。
    
      [程式碼](https://github.com/CongJie-Pan/HeartfeltAI_SE_MidtermPJ)
    
-   **台灣超速罰單管理系統**
    
    -   主導系統分析、協調任務，並確保超速罰單管理系統的成功完成。該專案與台北市儀表板整合，提升數據分析效率。
    
      [文件](https://github.com/CongJie-Pan/SA_FinalProject/blob/JayPan/%E6%96%87%E6%9B%B8%E6%AA%94%E6%A1%88/%E8%A6%8F%E6%A0%BC%E6%9B%B8/%E6%9C%9F%E6%9C%AB%E8%B6%85%E9%80%9F%E7%BD%B0%E5%96%AE%E8%99%95%E7%90%86%E7%B3%BB%E7%B5%B1%20%E8%A6%8F%E6%A0%BC%E6%9B%B8%20%E7%AC%AC%E4%BA%8C%E7%B5%84.pdf) [程式碼](https://github.com/CongJie-Pan/SA_FinalProject) [示範影片](https://github.com/CongJie-Pan/SA_FinalProject?tab=readme-ov-file#demo-video)
    
-   **零食販售網站：Foodie**
    
    -   領導團隊開發專注於販售韓式零食的前端網站，包括泡麵、飲料和糖果。網站具有溫暖的土色調設計和使用者友善的介面，提供直觀的購物體驗。
