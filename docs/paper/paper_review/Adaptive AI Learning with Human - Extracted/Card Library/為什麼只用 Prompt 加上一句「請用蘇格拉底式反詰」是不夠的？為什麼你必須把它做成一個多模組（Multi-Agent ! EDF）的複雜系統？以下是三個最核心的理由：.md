為什麼只用 Prompt 加上一句「請用蘇格拉底式反詰」是不夠的？為什麼你**必須**把它做成一個多模組（Multi-Agent / EDF）的複雜系統？以下是三個最核心的理由：

### 1\. 單一 Prompt 無法維持「長期策略狀態（State Persistence）」

- **Prompt 的極限**：如果你只在 System Prompt 裡寫「請用蘇格拉底式反詰」，模型在第一輪、第二輪會做得很好。但聊到第五輪時，因為 Context Window 的推進，模型會逐漸「忘記」自己的蘇格拉底人設，或者因為學生不斷索求答案，模型最終還是會「妥協」把答案吐出來。

- **系統架構的必要性**：這就是為什麼你需要 **Decision Agent**。Decision Agent 每一輪都在背後獨立運作，它不負責聊天，它只負責監控「學生現在懂了沒」。只有當 Decision Agent 判定「學生已經展現了足夠的建設性掙扎」，它才會更改 Dialogue Policy 允許系統給出答案。**這是一種硬體層級的強制控制，而非軟軟的文字 Prompt。**

### 2\. 單一 Prompt 缺乏「評估與退場機制（Adaptive Fading）」

- **Prompt 的極限**：奧卡姆剃刀的前提是「能解決問題」。但只靠 Prompt 解決不了「鷹架消退（Fading）」的問題。一個永遠都在反問的 AI（死板的蘇格拉底），對一個已經完全掌握概念的高階學生來說，是**極度煩人且浪費時間的**。

- **系統架構的必要性**：這就是為什麼你需要 **Evidence Agent** 與 **Learner Model (GUM)**。你需要一個背景程式去紀錄學生「剛才點擊了幾篇文獻、上一題有沒有答對」。當系統累積了足夠的 Evidence 證明這名學生已經是專家時，Decision Agent 就會把對話策略從「蘇格拉底反詰」切換回「Gemini 的高效摘要模式」。**沒有這些模組，你的 AI 就無法做到因材施教的「適應性（Adaptivity）」。**

### 3\. 單一 Prompt 是黑箱，無法進行「科學量化（Scientific Measurement）」

- **Prompt 的極限**：如果你只依賴單一 Prompt，當學生成績變好時，你根本不知道是為什麼。是因為模型今天心情好？還是因為學生比較聰明？大語言模型是一個黑箱。

- **系統架構的必要性**：回到你的碩士論文。你要做的是「科學化實驗」，科學需要**「變項與數據」**。當你把系統拆解為 EDF 架構時，每一步都會產生 Log：

   - Evidence Agent 輸出了幾次「學生處於認知失調」。

   - Decision Agent 決定了幾次「不給答案」。

   - 這些後台數據（Backend Log）是你證明「我的教學機制有效」的鐵證。只靠一句 Prompt，你什麼數據都抓不到，論文也就寫不出來了。

### 總結

奧卡姆剃刀是「如無必要，勿增實體」。
但對於一個**以教育為目的、必須長期追蹤認知狀態、且需要產出科學數據**的 AI 系統來說，EDF 框架或 GUM 記憶模組**「絕對是必要的實體」**。
