# **1\. 文科教學是哪個科目：文、史、哲、法律？**

# 建議聚焦於「歷史（History）」或「社會/公民（Civics）」。這兩個科目最需要處理「史料批判」、「多方觀點衝突」與「證據導向的價值判斷」。這不僅容易設計「衝突視角」的 AI 提示策略，也比純文學的感性賞析更容易建立客觀的量化評分標準。

# **2\. 回應是指文字嗎？還有更好的載體嗎？**

# 不僅是文字，更是「認知鷹架的互動介面（Cognitive Scaffolding Interface）」。如果只依賴文字對話框，AI 很容易淪為傳統的 Chatbot。更好的載體是結合 UI 設計，例如提供結構化的「思考選項按鈕」（如：找證據、提反例）、或是雙視窗設計（左邊對話探究，右邊同步編織論證畫布），將單純的文字回應升級為引導思考的系統機制。

# **3\. 「適合教學」的定義是什麼？什麼才叫做適合教學？**「適合教學」是指「能有效觸發學習者的認知失調，並推動其達到更高階的批判性思維」。在文科領域，直接給出完美摘要（讓學生覺得舒服、滿意）是「不適合」的假性學習。適合的教學必須能破壞學生對單一標準答案的依賴，迫使他們在互相衝突的觀點中進行「建設性掙扎」，進而自己建構出有深度的論點。

# **4\. 量化分析實驗（文科內容可量化嗎？如何實驗？）**完全可量化，需採用「文本結構評量（SOLO 分類法）」與「系統行為日誌（Log Data）」的雙重量化設。**實驗方法**：

# **A/B 測試**：對照組使用「單一總結回饋（如 Gemini）」，實驗組使用「衝突視角鷹架（AREQA）」。

# **量化指標 1（文本）**：對學生最終寫出的心得，使用 SOLO 分類法進行盲測評分（例如：單一觀點得 1 分，能統整衝突觀點得 3 分）。

# **量化指標 2（行為）**：分析 Backend Log，比較兩組學生在對話過程中的「思考停頓秒數」、「草稿修改次數」、以及「點擊參考文獻溯源的頻率」。這些客觀數據能精確反映出思辨歷程的深度。
