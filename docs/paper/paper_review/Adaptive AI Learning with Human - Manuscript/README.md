# Generative AI tutoring review manuscript

`main.tex` is an English integrative narrative review of generative AI tutoring, cognitive engagement, adaptive scaffolding, and independent learning. `references.tex` contains the cited works. The article is a review, not a report of a new experiment or a systematic review.

The review integrates five learning-science mechanisms from the theoretical-background notes: cognitive load, constructive engagement, metacognition, curiosity and motivation, and contingent support. A framework table connects each mechanism to a candidate tutor response and an outcome that requires empirical testing. AREQA appears only as a brief, unevaluated design illustration.

CongJie Pan is listed as the sole and corresponding author in `main.tex`.

## Preview

Upload `overleaf-preview.zip` to Overleaf as a new project, set `main.tex` as the main document if needed, and compile. The ZIP includes only the two TeX files required for the manuscript.

A local TeX installation can compile the manuscript by running `pdflatex main.tex` twice in this directory. No TeX engine was available in the drafting environment.

Before preprint or journal submission, verify the remaining `n.d.` reference metadata and all study-specific claims, compile and inspect the PDF, apply the target venue's style, and complete the author declarations.
