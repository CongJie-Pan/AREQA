## 4. 核心能力介紹區 (Features Section)

<上排>

### 1 PEDAGOGICAL POLICY 
  • 標題: 動態鷹架 / 認知策略
  • 內文: 拒絕給完答案就結束的「假性學習」。AREQA 會追蹤您的理解程度與情緒訊號，當漸入佳境時，自動將「完整解答」收攝為「提示與反問」，讓您獨立思考。

### 2 ASYNCHRONOUS CARE 

  • 標題: 主動關懷 / 信箱回覆
  • 內文: AREQA不是冷冰冰的聊天機器人。AREQA 會記住您昨天的卡關與焦慮，在適當時機發送延遲信件給予提示與鼓勵。不打斷專注，溫柔地把學習線索送至您手上。

### 3 PERSISTENT MEMORY 

  • 標題: 持續且長期的記憶系統
  • 內文: 真正有同理心的學習同伴。AREQA會濃縮你值得保留的學習偏好、易錯痛點與當前狀態，讓下一次對話能從既有的脈絡繼續，不再永遠從零開始。

<下排>

### 4 ACTIVE AVATAR 

• 標題: 即時角色扮演
• 內文: 您可以要求AREQA扮演您學習路上的關鍵人物。不管是蘇格拉底、曹雪芹、牛頓、川端康成等人物，AREQA都能搖身一變化身，並且依照您的學習狀況寫信給您，您也可以與他回信。

### 5 WEB SEARCH KNOWLEDGE 

• 標題: 網路知識檢索
• 內文: 整合關鍵字與外部搜尋。為每一句解答附上文獻依據與來源，給您可靠的知識地基。

### 6 INTENT EXPANSION 

意圖擴寫 / 洞察提問
• 內文: 學生往往不知道該怎麼發問。AREQA 會自動擴寫您簡略的提問，精準捕捉沒說出口的學習盲點，引導您把問題問得更具體、更深入。
