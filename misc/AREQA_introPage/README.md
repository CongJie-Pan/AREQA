# AREQA Landing Page Template

以 Vite + React 製作的 AREQA 品牌首頁樣板，已置入：

- `areqa_logo_v2.png`
- `areqa_icon_v3.png`
- `Muse.png`
- 六組 React/CSS Mini-UI
- Desktop / Tablet / Mobile 響應式版型
- Reduced Motion、鍵盤 Focus 與基礎 SEO

## 啟動

```bash
npm install
npm run dev
```

## 正式建置

```bash
npm run build
```

## 串接時需修改

1. 將 `進入學習大廳` 的 `href` 改成正式 Web App 路由。
2. 將 `mailto:hello@areqa.app` 改為實際入口。
3. 視正式品牌部署方式決定是否自託管 Noto 字型，以進一步改善首屏效能。
